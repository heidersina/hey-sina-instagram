# hey-sina-instagram

Fertige Bilder für geplante Instagram-Posts von @hey_sina_coaching.

Das Repository ist öffentlich, damit Buffer die Bilder beim Einplanen abrufen kann. Hier liegen nur PNGs, die ohnehin gepostet werden. Texte, Entwürfe und Unterlagen bleiben im Marketing-Ordner.

Ablage: `JJJJ-MM/TT_thema/01.png … NN.png` (Tag = Posting-Datum, Reihenfolge = Slide-Reihenfolge).
